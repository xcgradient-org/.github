# XC Gradient `.github`

This repository holds the organization-level GitHub metadata, issue templates, and shared configuration for XC Gradient.

## Contents

- `profile/README.md`: The public organization profile shown on GitHub.
- `ISSUE_TEMPLATE/`: Standardized templates for bugs and feature requests.
- `workflows/`: Shared GitHub Actions workflows for CI/CD across repositories.

## Contributing

We welcome contributions to our infrastructure and tools! Please ensure your changes comply with the repository structure and follow the existing patterns for CI/CD workflows and documentation.

## Repository Standards

Product code, automation, and operational docs live in their own repositories under [`xcgradient-org`](https://github.com/xcgradient-org).
