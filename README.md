# XC Gradient `.github`

This repository holds the organization-level GitHub metadata for XC Gradient.

## Contents

- `profile/README.md`: the public organization profile shown on GitHub
- shared documentation for how the organization is structured at a repo level

This repo is intentionally small. Product code, automation, and operational docs live in their own repositories under [`xcgradient-org`](https://github.com/xcgradient-org).
